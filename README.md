# LaTeX Delimiter Converter

Obsidian 公式分隔符一键转换插件。点击左侧 **Σ** 按钮，将当前笔记中复制来的 LaTeX 分隔符转换为 Obsidian 的美元符号语法。

| 转换前 | 转换后 |
| --- | --- |
| `\(x^2 + y^2\)` | `$x^2 + y^2$` |
| `\[E = mc^2\]` | `$$E = mc^2$$` |
| `\( x + 1 \)` | `$x + 1$` |

多行块公式也支持：

```text
\[
\begin{aligned}
a &= b + c \\
d &= e + f
\end{aligned}
\]
```

转换后：

```text
$$
\begin{aligned}
a &= b + c \\
d &= e + f
\end{aligned}
$$
```

## 使用

1. 打开需要处理的 Markdown 笔记。
2. 点击左侧 **Σ** 按钮，提示文字为“转换当前笔记的公式分隔符”。也可在命令面板运行 **LaTeX Delimiter Converter: 转换当前笔记的公式分隔符**，或在快捷键设置中为该命令分配快捷键。
3. 插件提示转换的行内公式和块公式数量；需要恢复时，按 `Ctrl+Z`（macOS 为 `Cmd+Z`）。

每次处理整个当前笔记。阅读模式下会自动切换到编辑模式，保留编辑器的撤销历史。只有点击按钮或执行命令时才转换。

## 转换范围

- 只处理成对的 `\(...\)` 和 `\[...\]`；未闭合或交叉的分隔符保留。
- 跳过代码块、行内代码、笔记开头的 YAML 属性、HTML 注释及已有的 `$...$` / `$$...$$` 公式。
- `\\(`、`\\[` 等转义后的字面内容保留。
- 为了让行内公式正常显示，去掉行内公式内容两端的空白；公式内部内容和块公式的空白、换行保持原样。
- 空的行内公式、内部含换行的行内公式，以及以转义空格结尾的行内公式会保留，避免生成无法显示的公式。
- 重复执行不会重复转换。插件不批量处理库内其他笔记，也不自动处理粘贴。

转换器采用保守的 Markdown 扫描规则；四个空格或制表符开头的行按代码处理，因此深层列表中的部分公式可能保留。异常嵌套时，完整的内层公式仍可能被转换，外层不完整的标记保留。

插件在本地运行，不连接网络，不保存设置。

## 安装

此插件目前通过手动安装使用。

1. 下载仓库中的 `main.js` 和 `manifest.json`（或下载 Release 中的同名文件）。
2. 在库目录下新建 `.obsidian/plugins/latex-delimiter-converter/`，将这两个文件放入其中。
3. 重新启动 Obsidian，打开 **设置 → 第三方插件**，启用 **LaTeX Delimiter Converter**。

需要 Obsidian 1.1.0 或以上。无额外运行时依赖，使用 Obsidian 公共 API。

## 开发

需要 Node.js 20 或以上。

```sh
npm ci
npm run check
```

`src/converter.js` 是独立的转换逻辑，`src/main.js` 是按钮和命令入口。`npm run build` 生成仓库根目录的 `main.js`，安装时只需要该文件和 `manifest.json`。测试使用 Node.js 自带的测试框架，覆盖转换边界和插件交互。
